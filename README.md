# Axe Spoofer

![Android](https://img.shields.io/badge/Android-10%2B-green)
![LSPosed](https://img.shields.io/badge/LSPosed-Compatible-blue)
![Version](https://img.shields.io/badge/version-v1.0.0-purple)

A modern LSPosed module for spoofing Android device identifiers.



> ⚠️ This project is intended for research, development, testing, and educational purposes only.

---

## Features

- Android ID Spoofing
- GSF ID Spoofing
- Advertising ID (Ads ID) Spoofing
- App Set ID Spoofing
- Media DRM ID Spoofing
- Device Fingerprint Management
- Hide Email Address
- Random Identifier Generator
- Per-app Spoofing Support


---

## Requirements

- Android 10+
- Root Access
- LSPosed Framework

---

## Download

Download the latest version from the **[Releases](../../releases)** page.

## Installation

1. Download the latest APK from the **Releases** page.
2. Install the application.
3. Enable the module in **LSPosed** and select the target apps.
4. Reboot your device.
5. Open Axe Spoofer and configure the identifiers you want to spoof.
